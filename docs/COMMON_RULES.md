# 공용 전투 규칙 (A~Z 초안)

엔진(`packages/engine/src/legacy/core.js`)을 정밀 검토해, 개별 전법과 무관하게 **모든 전투에 공통으로 적용되는 규칙**을 뽑은 목록.
전법별 함수(하이브리드 구조)는 이 규칙들을 "검증된 부품"으로 가져다 쓴다. 규칙이 확정되면 여기서 상태를 바꾸고 엔진·테스트를 맞춘다.

상태 표기
- ✅ 확정: 사용자 확인(R-xxx) 또는 인게임 원문
- 🎥 녹화: 전보 녹화로 확인됨
- ⚠ 잠정: v1.12b 해석·추정 (검증 대기 목록에 있음)
- ❓ 결정 필요: 근거가 없거나 엔진이 임의로 정함 — **사용자 확인 요청**

## 사용자 결정이 필요한 항목 (우선순위 순)
1. **H5 아군/우군** — "아군 = 자신 포함, 우군 = 자신 제외"로 전 전법 통일해도 되나?
2. **D3·D4 행동 순서 결정 시점** — 턴 시작 시 선공 버프가 그 턴 순서에 반영되나? 턴 도중 선공이 바뀌면 재정렬되나?
3. **E4 선공 차 70 이내** — 무작위 확률식(현재 0.5 + 차/140)인지, 단순 50%인지, 아니면 항상 높은 쪽인지?
4. **B5 전투 시작 발동 순서** — 유형별(전체 지휘 → 전체 패시브)인지, 무장별(선공 1위의 지휘·패시브 → 2위 …)인지?
5. **F12 평타 피신 시 추격** — 평타가 피신되면 추격 판정이 있나?
6. **H10·H11 조롱·혼란 범위** — 액티브 단일 대상에도 적용되나? 혼란은 아군도 때리나?
7. **G5 지휘 효과 소멸 시점** — 시전자 전사 즉시인가, 턴 종료인가?
8. **F10 반격 배율** — 반격 피해는 평타 몇 %인가(현재 50%)?
9. **K4 피신 → 저항 → 방어 순서**, **M5 디버프 제거 순서**
10. **O2·O3 연쇄 트리거** — 트리거로 발동한 효과가 다른 트리거를 또 발동시키나?
