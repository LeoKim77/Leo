# 공용 전투 규칙 (A~Z 초안)

엔진(`packages/engine/src/legacy/core.js`)을 정밀 검토해, 개별 전법과 무관하게 **모든 전투에 공통으로 적용되는 규칙**을 뽑은 목록.
전법별 함수(하이브리드 구조)는 이 규칙들을 "검증된 부품"으로 가져다 쓴다. 규칙이 확정되면 여기서 상태를 바꾸고 엔진·테스트를 맞춘다.

상태 표기
- ✅ 확정: 사용자 확인(R-xxx) 또는 인게임 원문
- 🎥 녹화: 전보 녹화로 확인됨
- ⚠ 잠정: v1.12b 해석·추정 (검증 대기 목록에 있음)
- ❓ 결정 필요: 근거가 없거나 엔진이 임의로 정함 — **사용자 확인 요청**
